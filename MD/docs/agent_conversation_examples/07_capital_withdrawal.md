## דוגמה 7 – משיכת כספי הון (Playbook #7)

**לקוח:** "יש לי 200,000 שקל בקופת גמל. כמה מס אשלם אם אמשוך את הכסף השנה?"

**[הסוכן מפעיל כלי: CALCULATE_CAPITAL_WITHDRAWAL_TAX]**
```json
{
  "name": "CALCULATE_CAPITAL_WITHDRAWAL_TAX",
  "arguments": {
    "withdrawal_amount_gross": 200000,
    "withdrawal_year": 2025
  }
}
```

**[תוצאת הכלי – לא מוצגת ללקוח]**
```json
{
  "withdrawal_amount_gross": 200000,
  "withdrawal_year": 2025,
  "tax_amount": 28000,
  "net_amount": 172000,
  "effective_tax_rate": 14.0,
  "marginal_tax_rate": 20
}
```

**סוכן:** "בדקתי עבורך את חישוב המס על משיכת 200,000 ₪ מקופת הגמל בשנת 2025:

**חישוב המס:**
- מס הכנסה: 28,000 ₪
- שיעור מס אפקטיבי: 14%
- מדרגת מס שולית: 20%

**סכום נטו שתקבל לידיים: 172,000 ₪**

שים לב: החישוב מתייחס למס הכנסה בלבד (ללא ביטוח לאומי ודמי בריאות).

לסיכום: אם תמשוך 200,000 ₪, תשלם מס של 28,000 ₪ ותקבל לידיים 172,000 ₪ נטו.

האם תרצה לבדוק סכום משיכה אחר, או לראות כמה תקבל אם תמשוך בשנה אחרת?"
