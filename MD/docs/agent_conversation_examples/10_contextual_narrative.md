## דוגמה 10 – נרטיב השוואתי (Contextual Narrative)

### דוגמה 10א – היוון קצבה עם השוואה מלאה

**תרחיש:** לקוח שואל על היוון קצבה. הסוכן מציג את התוצאה בהקשר מלא: לפני, אחרי, ומשמעות.

**לקוח:** "אני רוצה להבין מה יקרה אם אהוון 2,000 ש"ח מהקצבה שלי."

**[הסוכן מפעיל CALCULATE_PENSION_COMMUTATION עם Force Chaining אוטומטי]**

**תוצאת הכלי (לא מוצגת ללקוח):**
```json
{
  "commutation": {
    "lump_sum_gross": 400000,
    "tax_on_lump_sum": 72000,
    "lump_sum_net": 328000,
    "target_monthly_pension_reduction": 2000
  },
  "full_pension_comparison": {
    "total_gross_pension": 22000,
    "income_tax": 3500,
    "net_pension": 18500
  },
  "_force_chained": true
}
```

**תשובת הסוכן (מבנה נרטיב השוואתי):**

"בדקתי עבורך את אפשרות ההיוון. הנה התמונה המלאה:

**📍 המצב הנוכחי (לפני היוון):**
- הקצבה הברוטו המלאה שלך: **22,000 ₪**
- מס הכנסה: 3,500 ₪
- קצבה נטו: **18,500 ₪**

**📍 לאחר היוון של 2,000 ₪ מהקצבה:**
- סכום חד-פעמי ברוטו: 400,000 ₪
- מס על ההיוון: 72,000 ₪ (18%)
- **סכום נטו שתקבל: 328,000 ₪**
- קצבה חודשית חדשה: 20,000 ₪ ברוטו → **16,900 ₪ נטו**

**📊 המשמעות הכלכלית:**

| פרמטר | ללא היוון | עם היוון | הפרש |
|-------|-----------|----------|------|
| קצבה נטו חודשית | 18,500 ₪ | 16,900 ₪ | **-1,600 ₪** |
| קצבה נטו שנתית | 222,000 ₪ | 202,800 ₪ | **-19,200 ₪** |
| סכום חד-פעמי נטו | - | 328,000 ₪ | +328,000 ₪ |

**💡 משמעות הדבר:**
ההיוון ייתן לך 328,000 ₪ מיידית, אבל תפסיד 1,600 ₪ בחודש לכל שארית חייך. אם תחיה 20 שנה נוספות, ההפסד המצטבר יהיה כ-384,000 ₪.

**המלצה:** מבחינה כלכלית טהורה, הקצבה המלאה משתלמת יותר. עם זאת, אם יש לך צורך מיידי בהון (למשל לפירעון משכנתא) – ההיוון יכול להיות הגיוני.

האם תרצה שאבדוק תרחיש עם סכום היוון שונה?"

### דוגמה 10ב – ניתוח פרישה עם קונטקסט

**תרחיש:** לקוח שואל על הקצבה הצפויה בפרישה. הסוכן מתחיל מנתוני הצבירה הנוכחית.

**לקוח:** "כמה קצבה נטו אקבל אם אפרוש ב-2028?"

**[הסוכן מפעיל RUN_RETIREMENT_CASHFLOW_ANALYSIS]**

**תוצאת הכלי (לא מוצגת ללקוח):**
```json
{
  "retirement_date": "2028-01-01",
  "total_guaranteed_income": 22000,
  "income_tax": 3500,
  "net_income": 18500,
  "exemption_percentage": 67,
  "portfolio_summary": {
    "total_pension_balance": 1850000,
    "pension_funds_count": 3
  }
}
```

**תשובת הסוכן (מבנה נרטיב השוואתי):**

"בדקתי את תחזית הפרישה שלך לשנת 2028. הנה הניתוח:

**📍 הצבירה הנוכחית שלך:**
- סך צבירה פנסיונית: **1,850,000 ₪**
- מספר תכניות פנסיה: 3

**📍 התחזית לפרישה ב-01/01/2028 (גיל 67):**
- קצבה ברוטו צפויה: **22,000 ₪**
- מס הכנסה: 3,500 ₪
- **קצבה נטו: 18,500 ₪**

**📊 פירוט הפטור ממס:**
- אחוז פטור מקיבוע זכויות: **67%**
- סכום הקצבה הפטורה: 14,740 ₪
- סכום הקצבה החייבת במס: 7,260 ₪

**💡 המשמעות:**
הפטור מקיבוע זכויות חוסך לך כ-2,800 ₪ מס בחודש. ללא הפטור, המס היה גבוה יותר והנטו היה נמוך יותר.

האם תרצה שאשווה לתרחיש פרישה בגיל אחר, או שנבדוק אפשרות להפעלת פטור מקסימלי?"
