# 🚀 תוכנית עבודה: מקסום יכולות הסוכן (Phase II)

מסמך זה מתעד את תוכנית העבודה להרחבת יכולות הסוכן הפנסיוני לאחר השלמת שלב האימון הטכני הבסיסי (Phase I).

**תאריך יצירה:** 12.12.2025  
**סטטוס:** פעיל

---

## 📋 רקע

לאחר השלמת Phase I (דיוק בסיסי ועקביות), השלב הבא הוא **מקסום יכולות** – הרחבת הפונקציונליות והפיכת הסוכן ליועץ וירטואלי מקיף ומתקדם.

### מה הושלם ב-Phase I:
- ✅ מדיניות "מס הכנסה בלבד"
- ✅ סיווג יתרות (קצבתי/הוני)
- ✅ Playbooks מרכזיים (1-5)
- ✅ דוגמאות שיחה ורגרסיה
- ✅ לוגינג JSONL עם request_id
- ✅ אימון Workflow עם Few-Shot

## 🅰️ חזית A: הרחבת Workflows עסקיים (Feature Development)

החזית הזו מתמקדת בהוספת יכולות חישוב וניתוח חדשות, הדורשות פיתוח Backend (כלים) ואימון LLM חדש.

### A1: פיתוח כלי היוון קצבה
| פרט | תיאור |
|-----|--------|
| **שם הכלי** | `CALCULATE_PENSION_COMMUTATION` |
| **מטרה** | מאפשר ללקוח להוון חלק מהקצבה העתידית לקבלת סכום חד-פעמי (Lump Sum) |
| **לוגיקה נדרשת** | חישוב ערך נוכחי של קצבה עתידית, חישוב מס על ההיוון |
| **LLM/Agent Impact** | יצירת Playbook #6 (תרחיש היוון), הזרקת דוגמאות Few-Shot |
| **קבצים צפויים** | `app/services/commutation_service.py`, עדכון `llm_agent_tools_service.py` |
| **עדיפות** | גבוהה |
| **סטטוס** | ⏳ ממתין |

### A2: פיתוח כלי משיכת כספים חד-פעמית
| פרט | תיאור |
|-----|--------|
| **שם הכלי** | `CALCULATE_CAPITAL_WITHDRAWAL_TAX` |
| **מטרה** | חישוב המס המדויק על משיכה מיתרות ההון (גמל, השתלמות) לפני פרישה |
| **לוגיקה נדרשת** | חישוב מס שולי על משיכה, התחשבות במדרגות מס, פטורים רלוונטיים |
| **LLM/Agent Impact** | יצירת Playbook #7 (תרחיש משיכת הון), שיפור הבנת שאלות ממוקדות הון |
| **קבצים צפויים** | עדכון `capital_asset_service.py`, עדכון `llm_agent_tools_service.py` |
| **עדיפות** | גבוהה |
| **סטטוס** | ⏳ ממתין |

### A3: הוספת ניתוח הכנסות שוטפות

## 🔧 הנחיות טכניות

### יצירת כלי חדש (A1, A2):
1. **Backend**: יצירת service חדש או הרחבת קיים
2. **Tool Registration**: הוספה ל-`_get_tools_definitions()` ב-`llm_chat.py`
3. **Tool Implementation**: הוספה ל-`AgentToolsService` ב-`llm_agent_tools_service.py`
4. **Playbook**: יצירת Playbook חדש ב-`agent_playbooks.md`
5. **Examples**: הוספת דוגמה ל-`agent_conversation_examples.md`
6. **Regression**: הוספת שאלות ל-`agent_regression_questions.md`
7. **Few-Shot**: עדכון `playbook_loader.py` לתמיכה בדוגמה החדשה

### שיפור UX (B1, B2, B3):
1. **System Prompt**: עדכון ב-`llm_chat.py`
2. **Playbooks**: עדכון ב-`agent_playbooks.md`
3. **Examples**: עדכון ב-`agent_conversation_examples.md`
4. **Few-Shot**: עדכון `playbook_loader.py`
