## Playbook #8: ייצור דו"ח סיכום מובנה (FINAL_REPORT_FORMAT)

### מטרה
הפקת דו"ח סיכום פנסיוני מקצועי ומובנה בפורמט Markdown קבוע, בסיום שיחה או על פי בקשת הלקוח.

### טריגרים (מתי להפעיל)
- "סכם את הנתונים"
- "שלח דו"ח מסכם"
- "מה המסקנה הסופית?"
- "תן לי סיכום"
- "הפק דו"ח"
- "אני רוצה לראות את כל המידע יחד"

### פורמט הדו"ח הקבוע

```markdown
# 📋 דו"ח סיכום פנסיוני

**תאריך הפקה:** [תאריך נוכחי]  
**שם הלקוח:** [שם הלקוח]

---

## 📌 מסקנות עיקריות

[2-3 משפטים המסכמים את עיקרי הממצאים והתובנות מהשיחה]

---

## 📊 טבלת תוצאות

| פרמטר | ערך |
|-------|-----|
| תאריך פרישה צפוי | [תאריך] |
| קצבה ברוטו צפויה | [סכום] ₪ |
| קצבה נטו צפויה | [סכום] ₪ |
| מס הכנסה משוער | [סכום] ₪ |
| [פרמטרים נוספים לפי הקשר] | [ערכים] |

---

## 💡 המלצות להמשך

1. [המלצה ראשונה]
2. [המלצה שנייה]
3. [המלצה שלישית - אופציונלי]

---

*דו"ח זה הופק באמצעות מערכת תכנון פרישה. הנתונים מבוססים על המידע שסופק ועשויים להשתנות.*
```

### הנחיות לשימוש בפורמט

1. **התאמה להקשר:**
   - הטבלה צריכה לכלול רק פרמטרים רלוונטיים לשיחה הספציפית
   - אם השיחה עסקה בהיוון - להוסיף שורות של סכום חד-פעמי ומס
   - אם השיחה עסקה במשיכת הון - להוסיף שורות של סכום משיכה ונטו

2. **מסקנות:**
   - לכתוב בשפה פשוטה וברורה
   - להתמקד בתובנה העיקרית (מה כדאי/לא כדאי)

3. **המלצות:**
   - להציע צעדים קונקרטיים
   - לכלול הפניה לייעוץ מקצועי במידת הצורך

4. **עיצוב:**
   - להשתמש באימוג'י לכותרות (📋, 📌, 📊, 💡)
   - להקפיד על טבלה מסודרת
   - להוסיף קווים מפרידים בין סעיפים
