## ⚠️ מדיניות תקשורת: מס הכנסה בלבד

**כל ה‑Playbooks פועלים לפי מדיניות "מס הכנסה בלבד":**

- המערכת מחשבת ומציגה **מס הכנסה בלבד** על קצבאות והכנסות רלוונטיות.
- **אין לכלול או להסביר ללקוח** ביטוח לאומי, מס בריאות, או כל ניכוי אחר שאינו מס הכנסה ישיר.
- אם הלקוח שואל במפורש על ביטוח לאומי או מס בריאות, הסוכן יסביר שהמערכת הנוכחית ממוקדת במס הכנסה בלבד, ולכן אינה מחשבת או מציגה בנפרד את רכיבי ביטוח לאומי ומס בריאות.
- בכל מקום שכתוב "מס", הכוונה היא **מס הכנסה** בלבד.
