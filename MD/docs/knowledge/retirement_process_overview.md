# Retirement process overview

## מטרת התהליך
- לייצר תמונת מצב מקצועית וברורה לקראת פרישה
- להפריד בין איסוף מידע, ניתוח מערכת, והסבר מילולי
- להימנע מהבטחות או מסקנות מספריות שלא הגיעו מהמערכת

## איך לעבוד במערכת הזאת
- לעבוד לפי זרימה אחת ברורה בכל הודעת משתמש
- כשהבקשה מעורפלת או מערבת כמה נושאים
- לעצור ולבקש הבהרה קצרה
- לא לייצר פתרון שמאחד זרימות שונות

## רצף עבודה מומלץ לפרישה
- להבין מה המשתמש מבקש במילים פשוטות
- לזהות האם מדובר בניתוח פרישה, קיבוע זכויות, עזיבת עבודה, או משיכת הון
- לאשר שהמידע הבסיסי קיים במערכת או שהמשתמש סיפק אותו
- להפעיל את כלי המערכת הרלוונטיים רק כשצריך תוצאות מערכת
- לאחר קבלת תוצאות, להסביר במילים מה המשמעות ומה הצעד הבא

## איזה נתונים צריך לפני שמפעילים חישובים
- גיל פרישה מתוכנן או תאריך יעד לפרישה
- סטטוס תעסוקתי והאם יש אירוע עזיבת עבודה
- מרכיבי תיק פנסיוני עיקריים כפי שהם במערכת
- העדפות כלליות ברמת מטרות
- צורך בדוח או במסמך

## איך להסביר בלי מספרים
- להסביר את ההיגיון ולא את התוצאה המספרית
- לתאר מה המערכת בדקה ומה המערכת מחזירה
- לציין אילו החלטות קיימות עקרונית, בלי לבקש החלטה מהמשתמש
- להציע צעדים אופרטיביים להשגת מידע חסר, בלי להפוך את זה לשאלון

## טעויות נפוצות שכדאי למנוע
- לנסות לחשב מס או קצבה באופן עצמאי
- להציג אחוזים או מדרגות מס בלי פלט כלי
- לערבב בקשה לדוח עם ניתוח מילולי באותה תשובה
- לייצר לולאות של שאלות במקום צעד ברור קדימה
- להניח עובדות שלא קיימות בנתוני הלקוח

## כשחסר מידע קריטי
- לציין במפורש מה חסר
- להסביר למה המידע נדרש כדי להפעיל כלי או כדי לפרש תוצאה
- להציע דרך לקבל את המידע מתוך המערכת או מהמסמכים
- להמתין להשלמת המידע לפני הפעלה שמייצרת מצב חדש
